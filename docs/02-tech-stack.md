# Stack Table

| Category                   | Technology              | Purpose                                                        |
| -------------------------- | ----------------------- | -------------------------------------------------------------- |
| **Runtime**                | Node.js 24 LTS          | Run the backend                                                |
| **Language**               | TypeScript              | Type safety and maintainability                                |
| **Framework**              | Express                 | HTTP server, routing, middleware                               |
| **Database**               | PostgreSQL              | Store users, organizations, roles, permissions, sessions, etc. |
| **ORM**                    | Prisma                  | Database queries, schema, and migrations                       |
| **Cache / Infrastructure** | Redis                   | Rate limiting and session/token invalidation                   |
| **Authentication**         | Server-managed sessions | Secure, HttpOnly cookie-based authentication                   |
| **Password Hashing**       | bcrypt                  | Securely hash user passwords                                   |
| **Validation**             | Zod                     | Validate request bodies, params, and query data                |
| **API Documentation**      | Swagger / OpenAPI       | Document and interact with API endpoints                       |
| **Testing**                | Jest                    | Test framework                                                 |
| **HTTP Testing**           | Supertest               | Test Express endpoints                                         |
| **Containerization**       | Docker                  | Containerize the application and its dependencies              |
| **Collaboration**          | Git/Github              | Version control, branches, pull requests, code review          |
